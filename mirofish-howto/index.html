ثلاث نقاط قبل ما تبدأ

  • مفتاح OpenAI سرّي ومدفوع.رصيد الـ API منفصل عن اشتراك ChatGPT، واشتراك Plus ما بغطيه. ولا تلصق المفتاح بأي شات أو منشور.
  • مفتاح Zep مجاني.هو ذاكرة الشخصيات. الخطة المجانية فيها 10,000 رصيد بالشهر.
  • ابدأ بمحاكاة صغيرة.الاستهلاك عالي، فجرّب ملف قصير وأقل من 40 جولة. والنتيجة فرضيات تختبرها، مش إثبات إنه السوق بدّه فكرتك.

الخطوات باختصار

  1. اعمل مفتاح OpenAI من platform.openai.com واشحن رصيد الـ API.
  2. اعمل مفتاح Zep المجاني من app.getzep.com.
  3. افتح Claude Code على اللابتوب والصق البرومبت تحت. بطلب منك المفتاحين وبحطهم بملف .env فقط.
  4. افتح http://localhost:3000، وابدأ بملف قصير وعدد جولات قليل.
  5. ارفع فكرتك والسوق المستهدف، شغّل المحاكاة، واقرأ التقرير.

برومبت Claude Code

انسخه والصقه في Claude Code. لا تكتب مفاتيحك بالشات؛ لما يطلبها ضعها بملف .env فقط.

البرومبت (بالإنجليزي)
Set up MiroFish (https://github.com/666ghj/MiroFish) so it runs locally on my computer. Follow the official README and `.env.example`. Do not invent commands, environment-variable names, ports, or model IDs.

1. Check what is already installed: `git`, Node.js 18+ (with npm), Python 3.11 or 3.12 (not 3.13), and `uv`. Install anything missing, but ask me before any system-wide install.

2. Clone the official repo into this folder, or into a `MiroFish` subfolder if this folder is not empty:

   `git clone https://github.com/666ghj/MiroFish.git`

3. From the repo root, copy the example env file:

   `cp .env.example .env`

   On Windows: `copy .env.example .env`

4. Configure only these required values in `.env` for a first run:

   - `LLM_API_KEY` = my OpenAI API key
   - `LLM_BASE_URL` = `https://api.openai.com/v1`
   - `LLM_MODEL_NAME` = `gpt-4o-mini` unless I name another model
   - `ZEP_API_KEY` = my Zep Cloud API key

   Ask me for the two keys. Write them only into `.env`. Never print, repeat, log, or screenshot the key values. Never commit `.env`.

   Do not set `ZEP_API_URL` (the current official mainline rejects it and talks to Zep Cloud only).

   If I am not using a second "boost" LLM, delete the `LLM_BOOST_API_KEY`, `LLM_BOOST_BASE_URL`, and `LLM_BOOST_MODEL_NAME` lines instead of leaving placeholders.

5. From the repo root, install dependencies with `npm run setup:all`, then start both services with `npm run dev`. (`setup:all` only installs; it does not start the app.)

6. If anything fails, read the error, fix it, and try again. Useful checks:

   - Python must be 3.11 or 3.12, not 3.13.
   - Open the app at `http://localhost:3000`.
   - The backend API is `http://localhost:5001`. A 404 at `http://localhost:5001/` is expected; the health check is `http://localhost:5001/health`.

7. When it is running, give me:

   - the browser link: `http://localhost:3000`
   - how to stop it: `Ctrl+C` in that terminal
   - how to start it again later: `npm run dev` from the repo root
   - a first-run reminder: start with a short seed file (`.pdf`, `.md`, or `.txt` — not a scanned or image-only PDF), about 30 rounds and under 40, finish one full workflow, then scale up. The official UI is Chinese or English. After the simulation, read the report in the UI; a full Markdown copy is also saved under `backend/uploads/reports/<report_id>/full_report.md`.

Do not publish the app, do not expose it to the public internet, and do not create any other project.
