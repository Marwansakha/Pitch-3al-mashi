البرومبتPrompt

لما يسألك عن المفاتيح، عطه مفتاح OpenAI وبعدين مفتاح Zep. بيكتبهم بملف .env عندك، وما بيرجع يعرضهم. When it asks, give it your OpenAI key, then your Zep key. It writes them into .env on your machine and does not show them back. 

You are setting up MiroFish (https://github.com/666ghj/MiroFish) on my laptop from zero. I'm not technical, so do every step yourself, explain briefly what you're doing, and only stop when MiroFish is open and ready in my browser.

1. Detect my operating system (Mac or Windows) and use the right commands for it.
2. Check for git, Node.js (v18 or newer), Python (3.11 or 3.12) and uv. Install anything missing using the normal installer for my system (Homebrew on Mac, winget on Windows). Ask me before installing anything system-wide.
3. Clone the repo into a folder called "mirofish" in my home folder, and go into it.
4. Copy .env.example to .env.
5. Ask me for my two keys, one at a time, and write them into .env:
- LLM_API_KEY = my OpenAI key, with LLM_BASE_URL = https://api.openai.com/v1 and LLM_MODEL_NAME = a low-cost OpenAI model
- ZEP_API_KEY = my Zep key
Never show my keys back to me, never log them, and never commit or upload them anywhere.
6. Read the README and install all dependencies for both the frontend and the backend, using the commands it recommends.
7. Start the app (backend and frontend) the way the README says, and keep it running.
8. Check that both are actually up. If anything fails, read the error, fix it, and try again until it works.
9. Open the MiroFish page in my default browser for me.
10. Finish with a short summary:
- the link I should open (localhost)
- how long the first run should take
- how many personas it will use the first time
